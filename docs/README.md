# ドキュメント

このリポジトリの設計と規約の文書である。内容の種類ごとにディレクトリを分ける。

| ディレクトリ                       | 扱うこと                                                                                |
| ---------------------------------- | --------------------------------------------------------------------------------------- |
| [architecture/](./architecture/)   | アプリの構成。App Router、層と依存の向き、ファイル配置、コンテンツパイプライン          |
| [design-system/](./design-system/) | デザイン原則、デザイントークン、UI の用語                                               |
| [components/](./components/)       | コンポーネントの設計。余白とレイアウト、Props と JSDoc、状態や操作を持つ部品、Storybook |
| [conventions/](./conventions/)     | 書き方の規約。TypeScript、Panda CSS、パフォーマンス、テスト、ドキュメント               |
| [tooling/](./tooling/)             | 開発ツールの設定と使い方。Biome、設定ファイルの確認、MCP サーバー                       |

Claude Code が読み込む規則は、`.claude/rules/` と、`src/`・`src/components/`・`src/ui/`・`tests/`・`build/`・`docs/` の `.claude/rules/` にある。どれも規則の本文は書かず、この `docs/` の文書を指す。

| 規則の置き場                             | この `docs/` の文書の指し方                                                       |
| ---------------------------------------- | --------------------------------------------------------------------------------- |
| 各ディレクトリの `.claude/rules/docs.md` | `@` で取り込む。そのディレクトリのファイルに触れたときに読み込まれる              |
| `.claude/rules/always.md`                | `@` で取り込む。ディレクトリに属さない文書を、常に読み込む                        |
| `.claude/rules/` のそのほかのファイル    | `paths` と文書へのリンクだけを置く。リンク先は自動では読み込まれず、Claude が読む |
